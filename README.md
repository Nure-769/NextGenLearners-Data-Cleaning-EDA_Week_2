# NextGenLearners-Data-Cleaning-EDA_Week_2


Key Insights & Executive Summary

Exploratory Data Analysis was performed on applicants_cleaned.csv using Pandas, Matplotlib, and Seaborn. Below are the core findings:

Domain Popularity: Web Development received the highest volume of applications, generating nearly double the submissions of specialized tracks like Video Editing.

Application Timeline: Submissions peaked in May 2026 following initial program announcements, then gradually tapered off toward the deadline.

Acceptance Rate Analysis: Smaller categories, such as Video Editing, demonstrated a higher acceptance rate percentage compared to high-volume tracks like Web Development, indicating stronger relative candidate fit or less competition per slot.

Institutional Sourcing: Submissions were heavily concentrated in key institutions, with the Top 3 Universities accounting for nearly 40% of total applicants.

Submission Habits: Applicant activity peaked mid-week (Tuesday through Thursday), with a significant slowdown over the weekend.

Visualizations Included

Domain Distribution: Bar chart showing application counts across all 5 domain categories.

Monthly Application Trend: Line chart illustrating submission volume over time.

Status Breakdown: Pie chart for overall application statuses and a grouped bar chart for status breakdown per domain.

Top 10 Universities: Horizontal bar chart highlighting top-contributing institutions.

Bonus Chart (Day of Week): Bar chart analyzing submission patterns across days of the week.
